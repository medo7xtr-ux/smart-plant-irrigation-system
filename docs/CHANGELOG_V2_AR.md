# سجل تغييرات الإصدار v2.0.0

## الإضافات

أصبح كود Arduino يرسل قراءة جديدة كل ثانية بدلًا من كل دقيقة، مع الحفاظ على متوسط عشر عينات لكل قراءة والمعايرة الحالية. وأصبحت شاشة `Arduino / Live` تستطلع البيانات كل ثانية، فتنعكس القراءة الجديدة وأصغر تغير متاح تلقائيًا.

أصبح زر اختبار صحة البيانات والتدفق قابلاً لإعادة التشغيل في كل ضغطة. تبدأ كل دورة اختبار بمسح النتيجة السابقة، ثم تفحص واجهات API والصيغة والنطاق والمصدر ومسار القرار واتصال Arduino وتدفق أكثر من قراءة وheartbeat وعدم استخدام fallback.

أضيف تمييز صريح لمصدر القراءة داخل نتيجة الاختبار. إذا كانت القراءة الأخيرة من `ARDUINO_SERIAL` مع اتصال Arduino فعال، يظهر إشعار بأن البيانات سليمة وموثوقة. وإذا كانت من `DEVICE_TOOL`، يظهر إشعار تحذيري بأن البيانات غير موثوقة وقد تكون متلاعبًا بها. لا تُعامل بيانات الأداة على أنها Arduino.

## الحفاظ على التوافق

لم تُحذف وظائف المحاكاة أو الطقس أو التحكم اليدوي أو Rain Guard أو سجل التدقيق أو إيقاف المضخة الآمن. الإصدار `v1.0.0` محفوظ على GitHub كما هو، والإصدار الحالي يضيف فقط السلوك المطلوب.

## ملاحظة العتاد

يتطلب التحديث رفع `hardware/arduino_soil_sensor.ino` إلى Arduino. يجب اختبار الريليه دون المضخة أولًا، واستخدام مصدر تغذية منفصل للمضخة وعزل كهربائي مناسب. لا يمكن إثبات سلامة التوصيل الفيزيائي من الاختبارات البرمجية وحدها.
