# Smart Plant System (نسخة مصححة)

تم إصلاح مشكلة "Cannot find module 'serialport'" في هذه النسخة عبر تضمين المكتبات الأصلية وإعادة بنائها لبيئة ويندوز.

## طريقة التشغيل:
1. شغّل `Smart Plant System.exe` مباشرة.
2. لا يحتاج تشغيل Node أو Python أو تثبيت أي مكتبات إضافية.
3. إذا واجهت رسالة "Windows protected your PC"، اضغط على "More info" ثم "Run anyway".

يضم المجلد كود Arduino المتوافق، الأيقونة والشعار، ودليل التشغيل الكامل.
