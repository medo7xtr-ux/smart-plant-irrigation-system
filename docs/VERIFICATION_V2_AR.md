# تقرير التحقق — الإصدار v2.0.0

## الإضافات المنفذة

أصبح Arduino يرسل قراءة جديدة كل ثانية بدلًا من كل دقيقة، وأصبحت شاشة `Arduino / Live` تستطلع آخر البيانات كل ثانية. يحتفظ النظام بمنطق قبول القراءة ومصدرها وقواعد القرار كما هي، مع تحديث العرض عند وصول أي قراءة جديدة حتى لو كان التغير صغيرًا جدًا.

يبدأ كل ضغط على زر الاختبار دورة فحص جديدة؛ تُمسح النتائج السابقة أثناء التنفيذ، ثم تُفحص الصيغة والنطاق والمصدر ومسار القرار واتصال Arduino وتدفق القراءات وheartbeat وعدم استخدام fallback.

يُعرض مصدر القراءة داخل نتيجة الاختبار. عند وجود قراءة أخيرة من `ARDUINO_SERIAL` مع اتصال Arduino فعال، يظهر إشعار نجاح يقرر أن البيانات سليمة وموثوقة. عند كون القراءة من `DEVICE_TOOL`، يظهر تحذير بأن بيانات الأداة غير موثوقة وقد تكون متلاعبًا بها. لا تُعامل بيانات الأداة على أنها Arduino.
